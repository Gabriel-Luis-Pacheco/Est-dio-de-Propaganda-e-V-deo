# Premium release protocol — hard gate
Read before production; supersedes permissive delivery language. A render is not a release. Use labels **STUDY**, **ANIMATIC**, **REJECTED DRAFT**, **REVIEW CANDIDATE**, **RELEASE**. Never call a failed or unreviewed export final/premium/client-ready. User still receives best playable draft and limitations, not a refusal to deliver. The evidence gate cannot certify taste and self-scoring never substitutes for audience/human approval.

## 0. Capability budget (before concepts)
Inventory reference playback/audio, brand fonts/logo, licensed music/foley, geometry/backend, shading, compositing, compute, rendering time and reviewer access. Render representative 2–5s including actual hero, camera, shadows/contacts, text/transition and audio, not spinning primitives. A VTK/EGL geometry smoke test does not establish premium CGI. If physically convincing 3D cannot pass, redesign for exceptional intentional 2D or give labeled study; do not silently substitute simplified primitives. No expensive installation, external upload or purchase without authorization.

## 1. Taste calibration, not adjectives
Build a compact comparison board: 5 observed LOOK cases, 3 actual MOVES clips, 3 actually heard SOUND examples, each with source, timestamp, still/clip evidence, observed mechanism, why effective, transfer, and license. Never count inaccessible links, prior text summaries or catalog entries as observation. Use BUCK/JPMorgan for exchange and identity, ManvsMachine/Air Max for causal material metaphors, Ordinary Folk for staging/character, Antfood for distinctive sonic design. Read their cases, obtain legally usable reference evidence, don't copy assets. Compare same function (opening, payoff, CTA), not unrelated pretty pictures. Use 5 deliberately different concepts and eliminate literal icon catalogs, interchangeable logos and redundant copy. Develop an original visual grammar with rules for shapes, behavior, typography, lighting and transitions.

## 2. Design and edit before production
Create 3–5 key styleframes plus one rejected alternative; compare at native and phone size, grayscale, silhouettes. Every frame has composition hierarchy, intentional scale, graphic density, negative space, texture/material and lighting. No repeated text-left-object-right template by default. No decorative label, generic subtitle, cheap icon or fruit masquerading as brand logo. Use actual brand assets, current claim evidence and clearly identified schematic representations. Validate transaction limits and conditions.
Make two distinct animatics with guide audio, not just retimes. Define a single timeline in frame numbers shared by visuals, audio cues, captions and edit. No manual duplicate time arrays or global interpolation to fix editorial problems; derive cues and shot transforms from canonical timeline. Map question→action→consequence→turn→resolution. Every beat changes information/emotion; remove dead time rather than adding random movement. Plot 0.25s and per-shot change with scripts/analyze-pacing.py; try --fraction .01 and threshold 8; inspect suspected windows at native fps. A >1s low-activity interval or >50% low-motion shot triggers documented review, not automatic verdict. Intentional readable holds can pass; unresolved dead holds are P1. Test first second, first proof, mobile readability, CTA and final sound tail.

## 3. Motion craft
For every shot record state before/after, physical or semantic causal relation, subject trajectory, acceleration/spacing, anticipation, contact, rebound/settle, overlap, secondary motion, camera motivation, lens, staging, depth, light, material, exit/entry. Contrast macro/mid/wide and static/mobile shots based on meaning. Build transitions around shared state, shape, occlusion or motion direction; isolated scene resets need editorial justification. Real geometry alone does not imply cinematic quality; use bevel detail, normals, contact/shadow, environment reflection, selective depth of field, motion blur and compositing where justified. Test antialiasing, clipping, flicker, banding and legibility. Never call clipped left-to-right reveal kinetic typography by itself.

## 4. Sound as design
Three contrasting music/sound directions with actual audition, licensed high-quality sources or original score. No reliance on default sine mallet + noise taps for premium ads. Derive cue sheet from timeline; mark gesture anticipation, contact, cut, emotional turn, release and sonic signature. Compare attack and picture in frames/samples. Provide music, foley/SFX, optional VO stems and mix, rights ledger. Measure LUFS/true peak/dynamic range/silences by delivery spec; no arbitrary normalization as substitute for mix. Verify on speakers/headphones and in mono when possible. If no real audio listening, mark sound unreviewed and block release.

## 5. Review and regressions
Run scripts/release-gate.py JOB --manifest qa/release-manifest.json after any change to master. Build manifest from templates/release-manifest.json; every artifact is a nonempty local file with SHA256, review is tied to exact master bytes. Required independent human review (not invented agents) uses anchored 0–5: 0 missing, 1 broken, 2 amateur, 3 competent but below reference, 4 comparable in this dimension, 5 exceptional with evidence. No average masking a weak dimension. Zero unresolved P0/P1, each resolved issue needs rerender/retest evidence. Separate technical approval from creative judgment. Independently compare silent and audio-only, then combined playback against matched references. Blind A/B with rejected prior video when available, record preferences and reasons; no invented votes. Reviewers can disagree: record uncertainty. The script checks presence, integrity, basic metadata and declarations only, cannot detect lies or make taste judgments. Human review remains required for release.
Regression: [AbacatePay postmortem](../docs/abacatepay-postmortem.md), Dayform V2/V3; specifically reject rotating icon slides, 1→17 ratio for 1→1000 without clarification, cheap lettering on keycaps, last-second dead audio, synthetic sound without audition, missing brand assets, global retiming as a pacing fix. If the concept, hero or art direction fails, rebuild from blank; do not spend rendering budget polishing bad shots. Final output must be the best actually produced; if evidence gate fails deliver REJECTED DRAFT/REVIEW CANDIDATE and exact blocker, never release. No promises of future background work.

## 6. Execution checkpoints and repair playbook (mandatory, not just final QA)
- **G0 / feasibility:** locate the actual font, logo, brand kit, product evidence, renderer, sound library and reference media. Record path, version, rights, and tested capability. Missing capability triggers a deliberate concept change before spending full render budget, not an inferior version of the same idea.
- **G1 / concept:** create five competing one-line ideas, each with a cause→effect gesture, visual signature, commercial proof, and sound idea. Compare against professional equivalents; reject ideas whose logo can be replaced or which reduce to a sequence of icons. Pick one, drop nonessential features.
- **G2 / art direction:** create 3–5 actual frames from selected world plus a rejected alternative. Test mobile crop, silhouette, contrast, kerning, shot-scale variety, contact and visual identity. If weak, redesign composition, asset and lighting before motion. Use actual brand palette/type; do not invent a fruit logo. Do not add visual complexity as a repair.
- **G3 / editorial:** two decodable audiovisual animatics with materially different edit decisions. Record what the viewer learns at each cut, reading dwell, onset/contact/settle, and sound phrase. Fix dead time through causal events or removal, not constant camera motion. One canonical timeline; audio may use subframe sample precision, all visual beats/captions on frame boundaries.
- **G4 / hero proof:** 2–5s audiovisual clip of the hardest actual shot, at representative lookdev. Test scale, staging, dynamics, continuity, materials, contact, reflection, typography, sound sync, and benchmark comparison. Reject a plain spinning mesh as proof.
- **G5 / draft:** review playback at normal speed, silent and audio-only; inspect suspicious windows frame by frame, at mobile size and around cuts. Produce a defect log with timestamp, severity, cause, specific repair, version and rendered retest. For P1 concept or art failures, return to G1/G2; for pacing return to G3; for physics/camera/material return to G4; for sound redesign cues and re-edit. No obligatory polish of a failed concept.
- **G6 / release:** produce distinct hashed artifacts, verified decodable animatics/shot test/master, canonical timeline matching the master, pacing report with master/timeline hashes and reviewed windows, independently signed review record tied to master, and evidence per dimension. Run the gate. A changed master invalidates approval. A signature record is not cryptographically authenticated by this script. No invented reviewer.

Pacing workflow: `python scripts/analyze-pacing.py MASTER --timeline timeline.json --fps FPS --fraction .01 --threshold 8 --out qa/pacing.json` (FPS is canonical integer frame rate). Populate `review_windows` with start/end seconds, reason, decision (`intentional_hold` or `repaired`) and hashed inspection evidence. Cover every >=1s low interval and every beat >50% low activity. Generate again after rerender. The report is a diagnostic, not an artistic target; an intentional hold can be good. Avoid inconsistent measurement parameters across variants.
See [coverage matrix](../docs/creative-regression-coverage.md) for specific failures and preventive/corrective controls.
