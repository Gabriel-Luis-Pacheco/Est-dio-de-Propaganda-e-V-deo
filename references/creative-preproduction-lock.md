# Creative preproduction lock — mandatory for launch / premium / motion
25/11/2026. Applies to any brand, including BataTalk. Supersedes permissive fallback and "render first" instructions. The second AbacatePay film improved pixel activity but failed creatively again. A completed MP4 is not the goal of any individual gate. No full polish/render until G0–G4 pass. Use the supported gated launcher and [structured evidence contract](creative-evidence-contract.md). G5 reviews the actual draft; G6 is existing release gate plus stage history. A gate is an evidence check, not an automatic taste judge.

## Operating rhythm: planning, divergent work, review, causal repair
Start by allocating effort: discovery/creative 25–35%, art and animatic 25–35%, hero/lookdev 15–25%, final build/QA remainder; adapt to job, do not treat percentages as targets. Reserve a real rerender budget. If resources cannot support a comparable film, shrink scope to one memorable 5–10s idea or choose deliberate editorial 2D. Do not simply render 15–40s of low-quality CGI. No silent downgrade. Do not interrupt user for routine intermediate approvals: do internal review; mark genuinely unavailable human/auditory evidence and stop premium promotion. Deliver clearly labeled best proof/blocked draft, not a promise.
Run `python scripts/stage-gate.py JOB --through G0` then G1 etc. Use `templates/stage-manifest.json` as skeleton at JOB/qa/stage-manifest.json. A stage records exact files with SHA256, previous stage digest, concrete pass/reject observations per criterion and issue register. After recording actual reviews and paths, use `python scripts/stage-gate.py JOB --through G0 --seal` (repeat for each stage) to compute hashes and validate. Seal never marks anything passed. Later stages become stale after changes. Release additionally cross-checks that actual A/B animatics, canonical timeline and hero evidence match the release manifest. Reject returns to earliest causal stage; revise its evidence and invalidate dependent stages. A changed master invalidates G5 and release review. Do not backfill fictitious histories. A positive CLI result only permits advancing within this workflow, not release. Gate cannot prove chronology or judge art; review must be genuine. Use separate reviewer perspective; actual external reviewers only when available. User-requested 20 references etc. override minimums.

### G0 — actual capacity and truth (before concept)
Inventory actual renderer/version, real rendering throughput at target complexity, memory, antialiasing/lighting features, compositing, playable references, sound audition, brand assets and fonts, claims, rights, compute/time budget, review access. Download/verify actual wordmark and font; inspect website and demo/API with fictitious safe data. If assets or facts missing, choose a concept that does not misrepresent them; block branded premium if missing. Test representative geometry/material/light or deliberate 2D mechanism, not a spinning cube. Record measured test and plan A/B. If capability missing, change language before conceptual commitment or deliver limited study. Do not conflate VTK/EGL geometry with cinematic lookdev; no fallback to primitive slabs. Distinguish actual audio listening from waveform analysis. No unapproved spending or uploads.

### G1 — taste calibration and concept kill
Collect at least 20 references if requested, otherwise premium minimum 5 LOOK, 3 MOVES, 3 SOUND actually observed in respective medium; no double-counting inaccessible catalogs. For each selected case: source, timestamp, observed still/clip/audition, purpose, mechanism, why good, how transfer, what not to copy. Match opening to opening, hero to hero, end to end; learn techniques, not identities. Look at positive and negative examples (both AbacatePay failures). Compare five genuinely distinct concepts and reject at least four with reasons. One proposition, audience desire, credible proof, one visual grammar, surprising payoff and recognizable brand without logo. Use tests: competitor swap, one sentence recall, no-text story, remove-each-beat, commercial reason to choose brand. A moving icon, machine/track/currency conveyor or interchangeable feature catalog fails by default unless concept-specific payoff is demonstrated. Do not select idea solely because code is easy.
Required records: reference evidence, concept board with 5 distinct directions, rejection comparison, story/claim map and brand grammar. Each reference link needs recorded access limitation if not actually inspected.

### G2 — art direction before motion
Build 3–5 own representative styleframes plus rejected visual route. Use real brand assets and a comparison board at native and mobile size. Include opening, climax and signature; no generic HUD. Assess composition, focal hierarchy, negative space, contrast, silhouette, scale variation, typography, material richness, shadow/contact, background boundaries, color management, legibility, brand fit. For 3D show close-up lookdev, contact shadows, reflections and actual camera angle; for 2D show deliberate formal language and typography, not generic HTML cards. Test grayscale and thumbnails, safe crop and text contrast. Reject keycap money, toy tracks, low-detail slabs, washed green, empty floor, black background clipping and title-left/object-right repetition seen in AbacatePay. Basic primitives may be legitimate intentional designs but not placeholders masquerading as finished art. If hero styleframe alone is not portfolio-worthy relative to chosen reference, redesign. No motion effect can save ugly frames.

### G3 — editorial + sound animatic before final assets
Render two substantively different animatics with guide audio using the same proposition, different structure/cadence not global retiming. Compare from first frame to last, mute and with sound; decide what happens next and why, first meaningful action, proof, reversal and payoff. Map events on one canonical frame/sample timeline for camera, text, objects, edits and sound. Record before/action/consequence and novelty per beat, reading budget, hold justification, remove-the-beat test. Mark exact cut/transition in/out, overlaps, anticipation, attack, aftermath and sonic tail. Avoid time spent on transport, repeated copy, tracking a static object, unmotivated pauses. A lower pixel inactivity score does not establish progress. Re-edit if 2–4 seconds communicate one trivial fact, or proof arrives late without purpose. Final endcard hold must have reading purpose and deliberate sonic resolution.
Develop 3 distinct audio directions, audition actual material, shortlist licensed assets or original recordings, musical phrase/energy map and stems plan. Do not default to sine/noise/taps, generic corporate music or one effect per object. Without listening capability do not claim G3 audio passed; supply a limited silent/guide study. Select based on actual hearing, not LUFS.

### G4 — hero proof, craft, transitions and feasibility
Render a 2–5s representative hero at intended quality (full complex geometry/material/camera/typography/actual transition and guide sound); additionally prototype the highest-risk transition and signature. Must prove actual look and behavior, not geometry-only smoke test. Compare equivalent professional shots. For every shot: state before→after, dominant visual gesture, why it matters, path, acceleration/spacing, mass, anticipation, contact, deformation/reaction, secondary action, stagger/overlap, settle, camera motivation, focal length, focal target, occlusion/parallax, light and compositing, outgoing/incoming relationship. Design camera to reveal information, not to follow an unchanged object. Choose a motivated range of scale and tempo. Build transformation with correspondence/shape/material continuity: a boolean R$→check substitution is not a hero. No mandatory morph if a deliberately designed cut is stronger; show why. No arbitrary rectangular wipe, blank interstitial or static title layer as default. Animate typography semantically, test readability, avoid repeated headline/subtitle templates. Establish original brand motion rules. Test actual sound sync using timeline cues.
If the best hero falls below the reference, rebuild from blank or change language; no full draft until repaired. No adding particles, blur, faster camera or more features to disguise failure.

### G5 — draft, independent critique, revision
Render actual full draft at preview resolution after G0–G4. Inspect all beats, full linear playback at native fps, mute, audio-only and combined; sample sheets at 2fps plus frame-by-frame around transformations/cuts and final tail. Review small mobile and native display, grayscale, playback speed and audio mono where possible. Use independent human if available, otherwise separate adversarial passes labeled self-review (not independent). Compare directly against matched references and rejected baseline. Score each dimension anchored 0–5, no averages hiding failures: 0 missing, 1 broken, 2 amateur, 3 competent below reference, 4 comparable with evidence, 5 exceptional. Every criterion requires concrete observation, comparator, evidence; P0/P1 block. Review all novel issues in addition to regression cases, identify causal stage, correction, rerender and retest. At least one substantive A/B or revision comparison; no invented changes or votes. Bind G5 to exact master hash. Revisit G0–G4 if upstream assets change. After each new master repeat checks. Gate G6 uses release-gate.py; no human independent review = no RELEASE.
Verify decode, frame count, fps, resolution, color, crop, flicker, banding, clipping, loudness, silence, sync, claims and licenses separately from art. High resolution or motion activity is no quality proxy.

## Failure recovery (proactive)
If missing refs: use legally accessible stills and clips and state limitation; do not count text summaries. If no renderer: choose another proven one or deliberate 2D with reference comparison. If no audio listening: ask for real reviewer only when needed; label unapproved, never invent audition. If short budget: narrow concept, reduce shots, preserve hero quality. If brand assets inaccessible: obtain official public kit, do not recreate lookalike wordmark. If concept is weak: choose another of five, not surface polish. If gate fails twice for same cause, stop full rendering and run focused drills; replan scope. If deadline prevents quality, deliver strongest playable evidence and precise blockers. No indefinite loops or guarantees.
