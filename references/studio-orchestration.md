# Studio orchestration
One director owns concept, brief, claims, shot list, budget and acceptance. Do not spawn ten agents for a short edit; assign only where actual parallel work improves outcome. Specialists must produce artifacts, not roleplay.
- Strategy/copy: audience, offer, one promise, proof, hook alternatives.
- Art direction: reference board with LOOK/MOVES/EDIT/SOUND, 3–5 styleframes, palette/type/material/light, reject variants.
- Storyboard/editor: event map, A/B animatic, shot list, duration rationale, reading times.
- Motion/3D: per-shot mechanisms, curves/rigs/camera, blocking, short motion test, reproducible render.
- Sound: audition, license ledger, score/cues/stems, sync and mix.
- Independent critic: blind compare before/after, timestamps, P0/P1 and exact corrective action.
- Producer: environment preflight, cache, render/proxy/versioning, export and handoff.
All share one timeline/shot manifest; no writes to same files concurrently. Director approves at concept, animatic, motion test, rough and master. If no subagents, do independent passes with distinct artifacts; never claim reviewers existed. Token efficiency: load only routing-relevant modules, keep compressed evidence, no repeated web searches after pinning verified reference, render the riskiest 2–5s first, cache shots/stems and reuse safely, no infinite loops. Stop when creative gates pass or resources genuinely prevent; report blocker.
