# Motion craft laboratory — skill acquisition, not a list of effects
For each mechanism: select a matched professional 2–5s reference, isolate geometry/timing/material/sound, sketch key poses, implement low-res proof, render with the actual backend, inspect linear and frame-by-frame, compare, document rejected variant, improve, archive editable source+preview+license+review. Only promote to reusable arsenal after real review. No borrowing protected art/audio. A mechanism must serve the campaign; do not force them all into a shot.

| Drill | Build / reject / acceptance evidence |
|---|---|
| Concept specificity | 5 concepts for same brief; remove logo and copy; reject generic conveyor; show recognizable brand grammar and a visual reason to choose product. |
| Silhouette & typography | 3 compositions in grayscale and mobile crop; actual fonts, optical spacing and semantic text movement; reject generic labels/oversized center text; readable rest poses. |
| Object design / lookdev | Design distinctive hero silhouette, macro/mid/wide stills, meaningful material contrast and contact; reject primitive stack with plastic shader. Test geometry bevel, shadows, reflectance, environment; deliberate 2D alternative if needed. |
| Physical morph | Match landmarks between source and target; intermediate deformation, volume/shape continuity, anticipation and settle; reject boolean swap; review 5 key poses + full fps. |
| Causal choreography | Action A creates visible response B then C; independent curves, mass, arcs, stagger, overlap; compare to linear translation, remove decoration. |
| Camera language | Make static, macro, dolly/orbit and occlusion variants; select only reveal-bearing move, preserve axis and legibility; compare full scale changes, not tracking. |
| Transition pair | Start/end with shared state, silhouette or directional gesture; make match cut, physical occlusion or action cut; compare to arbitrary wipe, check every frame around seam. |
| Pacing | Two editorial structures with same story; map novelty and payoff, remove transport, compare readability, intentional holds; no pixel-metric optimization. |
| Audio identity | Three genuinely different auditioned cues; layer licensed/recorded foley with music, silence and signature; choose by listening, sync via frame/sample cue map, check tails, stems, mono. No synthetic-only preset by default. |
| Compositing | Compare raw vs corrected render: contrast, depth, anti-alias, motion blur/DOF if motivated, color, contacts, grain only if justified; reject clipping/banding/edge halos. |
| Endcard | Three payoff-to-logo transitions with official brand kit; readable stable end pose, resolved sonic phrase, no arbitrary dark frame/wipe. |
| Product proof | Capture actual flow/API result with fictitious safe data and source; distinguish schematic; compare no-text comprehension and honest benefits. |

Record failed and passed evidence in job; each new high-risk mechanism receives a 2–5s proof. For reuse, store exact versions, source path, parameter ranges, reference provenance and what it does NOT solve. Do not label drills validated until rendered and reviewed.
