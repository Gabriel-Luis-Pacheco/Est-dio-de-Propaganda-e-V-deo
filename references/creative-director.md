# Creative Director / taste calibration
A director chooses what the audience should feel, know and remember. Use a one-sentence idea, not a list of features. Explore at least three **different narrative mechanisms**: (a) literal action/proof, (b) physical metaphor, (c) human situation/contrast. Select on specific brand fit, memorability, truthful proof, readability, feasibility and sound potential. If the logo can be swapped with no other changes, reject. Never claim fictitious features in real ad.
 
Taste is contrast between observable alternatives, not adjectives. Build pairs for same message: a weak draft and a considered revision. Evaluate focus, scale, negative space, grouping (Gestalt), contrast, color, typography (optical kerning, line breaks, alignment), materiality, perspective, copy and visual cause/effect. Inspect 360px thumbnail and grayscale; judge by what the eye reads first. Record screenshot, time, reason, correction, before/after. No fake human score. 
| Failure | Alternative to test |
|---|---|
| Everything centered in identical cards | One dominant object; asymmetric scale and controlled negative space |
| Four colors and shadows compete | One contrast axis; group supporting objects by value and proximity |
| Identical ease-in-out for different masses | Assign trajectory, inertia and settle per object; overlap causal reaction |
| Five disconnected slogans | One idea that changes state and earns payoff |
| Vignette followed by a slow reveal | Start on a meaningful physical action or consequence |
| Music pasted on last | Edit to phrases, audition multiple directions, choose cues before animating |
 
Taste feedback uses objective annotation plus human pairwise preferences; don't convert preference to universal law. Negative examples from Dayform V2/V3 and lab V1 are real rejection evidence, not generic claims. Review positive reference footage, not just description. If visual reference and user feedback conflict, user preference for that job wins. Store new learnings as reusable evidence, not blanket bans.
