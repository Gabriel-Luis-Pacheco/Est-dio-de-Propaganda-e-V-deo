# Structured creative review — mandatory for premium
Use the preproduction protocol; these are concrete evidence formats, not aesthetic defaults.
Full render: `python scripts/run-render.py JOB -- <renderer command and arguments>`. It runs G0–G4 first; no renderer launch on failure. Preview/animatic/hero drills may run earlier; do not falsely present them as production. Direct renderer invocation bypasses the wrapper and violates the workflow; it is not a sandbox.
Use [machine-readable examples](../templates/creative-records.example.json) as schemas, never as evidence. Each structured record below is JSON at the path specified by the corresponding stage check evidence. Nested media evidence is relative to JOB with SHA256. Use actual observations and rights. Never publish private/unlicensed reference media. If evidence cannot be lawfully retained, block premium approval. `--reset` invalidates the named stage and descendants; re-review and reseal. `--seal` refuses changed evidence/predecessor on passed stages. Hashes are not signed timestamps.
## G1: five_concepts / reference_calibration
five_concepts: {"concepts":[{"id":"c1","premise":"...","visual_mechanism":"...","brand_specificity":"...","payoff":"...","decision":"selected|rejected","reason":"..."}]}. Five distinct mechanisms, one selected. Reject alternatives with concrete reasons, test competitor swap and silent recall.
reference_calibration: {"requested_minimum":20,"references":[{"id":"r1","role":"LOOK|MOVES|SOUND","url":"https://...","timestamp":"...","observed":true,"mechanism":"...","transfer":"...","avoid":"...","rights":"...","media":{"path":"refs/clip.mp4","sha256":"..."}}]}. LOOK is a still/clip, MOVES a clip, SOUND audio actually heard. Distinct evidence and distinct URLs per role (5/3/3). Requested minimum is actual user request, 0 if unspecified. Source may serve multiple roles with distinct evidence.
## G2: styleframes
{"frames":[{"id":"f1","role":"opening|hero|signature|other","decision":"accepted|rejected","score":4,"observation":"...","comparison":"...","reason":"...","media":{"path":"frames/f1.png","sha256":"..."}}]}. Three accepted plus rejected route. Native/mobile/grayscale, crop, shadows, lighting, type, brand. Each accepted >=4/5 against matched reference; no self-awarded grades without evidence.
## G3: canonical_timeline / audio_directions
Keep existing timeline fields fps,width,height,duration,beats,audio,captions. Every beat adds before, action, consequence, novelty, camera_reason, transition_reason, reading_hold_reason, audio_cue. Explain what changes and why it deserves frames. No duplicate clocks.
{"directions":[{"id":"a1","decision":"selected|rejected","auditioned":true,"intent":"...","heard_observation":"...","reason":"...","rights":"...","media":{"path":"audio/guide1.wav","sha256":"..."}}]}. Three actual auditioned guides, one selected. A/B animatics must differ visually, not identical footage with new metadata; decoded hash detects identical normalized visual sequences (not every re-encode or superficial edit); MOVES evidence must contain multiple frames. This is narrow duplicate detection, not semantic analysis.
## G5: regression_review
{"regressions":[{"id":"V2-01","decision":"passed|not_applicable","timestamp":"...","observation":"...","reason":"...","evidence":{"path":"qa/clip.mp4","sha256":"..."}}],"beats":[{"id":"same-id-as-timeline","dimensions":{"composition":{"score":4,"observation":"...","comparison":"..."},"motion":{},"pacing":{},"continuity":{},"typography":{},"commercial_clarity":{},"sound_sync":{}},"evidence":{"path":"qa/beat.mp4","sha256":"..."}}]}. Retest V2-01..V2-18, justify any not applicable. Each beat every dimension, no averages hiding bad shots. Add novel issues to existing ledger. Review all affected stages after changes. All concrete observation/reason/comparison fields require specific sentences, not yes/no; minimum words are only a superficial check.
## Practical review order
1. Creative director: after silent playback what do I remember? Could any competitor use it? Is hook meaningful?
2. Art director: native side-by-side composition, materials, type, scale; identify weakest frame and redesign.
3. Editor: full linear playback; dead transport, repeated information, unclear payoff and unreadable cuts; re-edit.
4. Motion director: five key poses plus full fps; spacing, weight, anticipation, contact, continuity; replace generic transitions.
5. Sound director: actual listening separately and with picture; texture, contrast, phrase, sync, ending. No listening, no pass.
6. Commercial reviewer: verify assets/claims, reason to choose, product proof or explicit metaphor, CTA.
7. Independent reviewer: compare weakest beat against matched reference, reject unresolved P0/P1 and grades below 4. No invented external review.
Record strongest objection and correction each pass. New defects are as blocking as known ones. Shrink scope when quality cannot be achieved, rather than produce a polished bad film. Technical pass is not taste certification.
