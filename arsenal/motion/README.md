# Motion arsenal — building blocks, not quality claims
24 locally authored SVG mechanisms (2D, some projected/2.5D; no actual 3D). Pure frame function, deterministic, palette and label editable. Source `mechanisms.mjs`, gallery `index.html`, `render.mjs` generates frames. Start local server `python -m http.server 8765` in repo and open /arsenal/motion/; replay each study. `node tests/test_motion.mjs`. Render SVGs to PNG using a compatible renderer (rsvg-convert or browser), FFmpeg 30fps, no audio by default. All are studies, not approved advertising. 192 frame determinism/variation checks executed in V8; visual and MP4 validation separate.
 
For professional repertoire consult [external-shots.json](external-shots.json): 124 upstream Video Shotcraft shot cards, 150 preview variants reported by upstream. Pinned Apache-2.0 code source, read individual shot cards, dependencies and third-party asset licenses before use; do not mirror media. Download/install in isolated local workspace only with authorization. Inspect preview and choose by function. These are indexed, not individually tested by us. 
Do not concatenate stock mechanisms. Use only where causal, adapt timing, palette, camera and material to concept; render and compare one shot before committing. For high-end 3D use Blender/C4D/Houdini when available, not these 2D SVG prototypes.
