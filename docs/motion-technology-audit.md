## Exclusões e reclassificação
Retirar da rota ativa as duplicações de catálogos/motion prompts, receitas redundantes HTML+Playwright, bibliotecas de estilos genéricos, kits estudantis e presets (não provaram ganho neste caso). Não afirmar que tais repositórios são ruins por definição; sua inclusão como dependência padrão não foi justificada. Histórico permanece em upstream-audit e reference-lab para rastreabilidade. A rota corrente é motion-stack.md.
Rebaixar Pillow/Canvas 2D improvisado, FFmpeg zoompan, screenshot-only, CSS perspective-only para auxiliares/protótipos; não aprovar filme premium 3D com esses métodos isolados. VTK permanece contingência de 3D genuíno, com gate de lookdev. Não remover FFmpeg, Python ou 2D profissional; eles têm função legítima. Não instalar softwares comerciais sem autorização.
