# Benchmark — compare outputs, not documentation
12 fixed briefs in briefs.json. Same input, asset rights, compute/model/tool access and budget per pair. Baseline without skill vs current skill; run with multiple seeds when possible, preserve raw outputs, record runtime/cost/errors. Randomize labels; independent human judges watch full video with sound, first without context then brief. At least 3 raters for exploratory signal, more for reliable inference. Rate 0–5 anchored: 0 broken, 1 weak, 2 basic, 3 competent, 4 professional, 5 exceptional. Criteria: idea/originality, art direction, motion/spacing, pacing, sound, clarity/proof, finish, brand/mission fit. Record timestamps and rationale; tie allowed; report n, preference counts and disagreement, not spurious precision. P0 safety/rights/claims or broken output disqualifies. Human listening required for sound. Independent machine tests verify structural/technical requirements only. No metric certifies taste. 
Each case: save brief, version/SHA, asset hashes, renderer, seed, source, mp4, QA, blind labels, judges, votes and exclusions. Run comparison of skill vs baseline before claiming improved output. Benchmark status is not_run until artifacts and independent scores exist. New version can be technically sound without artistic validation. Track results in `results.jsonl` locally; don't publish protected media.
